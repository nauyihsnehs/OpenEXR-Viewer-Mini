# Tiles 核对清单

覆盖 `OpenEXR Test Images/Tiles` 的全部 3 张 EXR。这组样例均为普通单层级（ONE_LEVEL）
Tiled。现已增加 Mipmap 支持，见 [MultiView 核对清单](multiview-images.md)；Ripmap 和 Deep
仍在预览和整文件原始导出时明确报错。
样例文件未修改或移动。

## 文件头与静态审查

| 样例 | 文件头信息 |
| --- | --- |
| GoldenGate | RGB HALF，1262×860，128×128 tiles，PIZ；窗口起点 (0,0)。 |
| Ocean | RGB HALF，1255×876，128×128 tiles，ZIP；窗口起点 (0,0)。 |
| Spirals | RGBA HALF＋Z FLOAT，1040×1040，287×126 tiles，PXR24；data window 为 (-20,-20)～(1019,1019)，display window 为 (0,0)～(999,999)，具有非标准 chromaticities。 |

- 预览在像素分配前检查 part 类型和层级模式。Tiled 使用 `TiledInputPart`，
  扫描线沿用 `InputPart`，两者共享现有通道缓冲及后续数值处理。
- Tiled 按 tile 行读取第 (0,0) 级。`Slice::Make` 使用 data window 的文件坐标，
  不开启 tile 相对寻址；边缘由 OpenEXR 处理，不另建 tile 拼接缓冲。
- 读取器构造加源文件锁，每批绑定 framebuffer 和读取也在同一锁内；批次之间释放锁。
  Tiled 解码每行前后检查取消，失败或取消不发布部分结果。渲染继续捕获完整不可变数据。
- 源统计、异常连通区域、RGB 色域转换在完整读取后按原顺序执行。源值／显示值隔离、
  黑底预览、文件坐标、Alpha 与独立 Z 的标量页面保持既有语义。
- 活动图层原始导出读取模型源缓冲；整文件原始导出按源类型读取。
  输出一律沿用扫描线写入，不携带 `tiles` 属性，保留既有窗口、通道和色域元数据选项。
- 复制和预览导出继续先缩放基础图再绘制异常标记；刷新和极简窗口没有新增状态字段。
  Attributes 已有 tile 描述显示，无需新控件或公共模型接口。
- 补充未执行的测试代码：标量与 RGB/RGBA、多 tile 行、边缘残块、小于单 tile 的图像、
  非方形 tile、负起点和不同窗口、非标准色域、零 Alpha 发光、FLOAT Z、跨 tile 异常区域、
  同源并发图层、预先取消、末尾 tile 截断、扫描线导出往返及 Deep／Ripmap 拒绝。
- 完成调用路径及补丁空白检查。

这些是文件头与源码的静态审查，不代表画面验收通过。本轮未编译、启动查看器或运行测试。

## 待人工核对的交互与输出

1. 同时打开合成颜色和多个独立通道，快速切换、关闭与刷新；在读取期间关闭文档，
   检查取消响应和是否出现旧图层数据串入。中途取消的时序仍需运行验证。
2. 检查缩放、平移、极简窗口、刷新恢复以及异常定位开关；标记在完整图像局部坐标中绘制，
   跨 tile 的异常区域不应被切开。原文件没有异常时使用测试夹具核对。
3. 复制和 PNG/JPEG 预览导出分别检查原尺寸与缩小尺寸，黑底及标记位置与界面一致。
4. 活动图层、独立 Z 和整文件原始导出选择 FLOAT 与 ZIP 等无损压缩；重新打开确认是扫描线
   存储，通道值、数据／显示窗口正确，基础元数据保留色域、None 去除色域。
   Spirals 的源 PXR24 解码结果是比较基准，不追溯压缩前的数据。
5. 不完整或损坏 tile 必须报错，不能把未读区域补零后显示为成功图像；Ripmap 和
   Deep 文件明确拒绝，且不产生成功的整文件原始导出。
