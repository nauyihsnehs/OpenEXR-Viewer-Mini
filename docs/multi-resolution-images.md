## Resolution Level 菜单

- 入口为 **View → Show → Resolution Level**，替代旧 Mipmap Level 菜单。Mipmap 用平面列表，
  旧第 L 层对应 `(L,L)`；Ripmap 用 **X level → Y** 分级菜单，最终条目列明 `(X,Y)` 及当前显示画布尺寸。
- 进入 X 子菜单不读取图像，点击最终组合才切换；所有最终条目互斥，勾选已成功显示的层。
  当前文件只有一个有效组合时禁用菜单。
- Kapaa 的横向各层尺寸为 799、400、200、100、50、25、13、7、4、2、1；
  纵向各层尺寸为 546、273、137、69、35、18、9、5、3、2、1。
  `(1,0)` 为 400×546，`(0,1)` 为 799×273，`(1,1)` 为 400×273，`(10,10)` 为 1×1。
- 使用当前层原生形状和源像素比例；只降低横向分辨率时画面变窄，这是所选层的实际像素形状。
  100% 时当前层一像素高对应一个逻辑像素，不额外补偿横纵缩减差异。
- 选择按文件统一，左右眼、Anaglyph 和独立通道一起切换，其他文件不变。保留曝光、色调映射、
  色带、手动范围及异常开关；Auto 按所选层重新计算。Fit 重新适应，手动缩放保留倍率与相对中心。
- 快速切层、返回已显示层取消、刷新和进出极简窗口应保留正确组合；任何已打开页面读取失败，
  所有页面及源文件均保留旧状态。刷新后组合或配对消失应明确报错。
- 多 part 可选集合是实际有效组合的交集。混合 Mipmap／Ripmap 只能选择双方都有的对角层，
  带扫描线／ONE_LEVEL part 的文件只能选择 `(0,0)`；通过夹具检查，不能用各轴层数的笛卡尔积代替。

## 坐标、标记与导出

Data Window 使用 OpenEXR 的 `dataWindowForLevel(X,Y)`，起点保持不变。应用的 Display Window
保留原显示起点，宽高分别按 X、Y 和源 ROUND_DOWN／ROUND_UP 缩减，最小为 1。读数标注当前组合，
表示该层实际采样文件坐标，不表示第 0 层对应像素。标题尺寸为数据缓冲尺寸，菜单尺寸为显示画布尺寸。

- 源统计和异常区域仅来自当前层真实源样本。负起点、不同窗口、非方形像素与边缘异常位置需用夹具核对。
- 复制及 PNG/JPEG 预览按所选层显示画布输出；保持透明补空、JPEG 黑／白背景，异常标记在最终尺寸绘制。
- 活动及整文件原始 EXR 只保存所选 `(X,Y)`，使用扫描线；没有 `tiles`，不保存整个金字塔。
  保存对话框明确提示组合及该限制。被预览裁掉的当前层数据仍保留在原始输出中。
- 使用 FLOAT＋ZIP 往返核对原值、通道、part 顺序、窗口、像素比例、色域及视图属性；Basic／None 规则保持原样。
- 普通源图层 HDR／曝光序列使用当前层显示用线性数据。Anaglyph 仍只允许预览与整文件源数据导出，
  拒绝活动原始、HDR 和曝光序列。切层准备期间保存针对已提交的源文件及组合。
