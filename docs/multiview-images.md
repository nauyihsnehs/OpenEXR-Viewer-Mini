## 样例与默认视图

| 文件 | 源结构 | 待人工核对 |

| LosPadres | 689×1000，扫描线 RGB；right/left | Default 右眼；切换眼别与标签一致，原始导出保留 right/left 顺序。 |

| Fog | 1000×672，扫描线 Y；left/right | Default 左眼；左右眼均为单通道 Colormap 页面，原值和眼别一致；Anaglyph 可用、左右原始读数正确。 |

Fog 独立 Y 默认灰度、0～1；Anaglyph 把 Y 当作线性灰色，使用 RGB 页面的曝光、色调映射或
伪彩色后合成立体图。两者默认明暗可能不同，这是显示路径的区别。`ilut`、`xDensity` 继续作为
属性展示，不据此额外执行 LUT 或改变物理显示尺寸。

1. 在 **View → Show → Resolution Level** 切换。100% 时当前层一个像素高对应一个逻辑像素，
   Mipmap 第 L 层标为 `(L,L)`，不把小层放大到第 0 层尺寸。菜单尺寸是当前显示画布尺寸；标题尺寸是当前数据缓冲尺寸。
2. 同时打开左右眼、独立通道和 Anaglyph，切层后全部使用相同层号；其他文件不变。
3. 曝光、色调映射、色带、手动范围和异常开关保留，Auto 按当前层源值重新计算。
   Fit 重新适应，手动缩放保留倍率及画布相对中心；刷新和进出极简窗口保留层级。
4. 快速切层、返回已显示层取消请求、关闭文档；确认不会闪现旧请求或半数页面切层。
   有任一读取失败时应保留原层级、全部旧页面及源文件。刷新后层或配对消失应报错，不自动换眼。
5. 文件可选层为所有 parts 的交集，含扫描线或 ONE_LEVEL 的混合文件只能选第 0 层。
   Ripmap 现已支持，见 [Multi-Resolution 清单](multi-resolution-images.md)；Deep 继续拒绝。
   此组样例没有混合 parts，需用测试夹具核对。

数据窗口采用 OpenEXR `dataWindowForLevel`，起点不变；应用的当前层显示窗口保留原显示起点，
宽高按层及 ROUND_DOWN/ROUND_UP 缩减，至少为 1。后者是查看器的显示约定。
悬停坐标是当前层采样文件坐标，带层号，不表示第 0 层对应像素。负起点、不同显示窗口、
裁剪、补空、非方形像素和异常标记位置使用夹具核对；源统计只计当前层实际源样本。

## 复制与导出

- 全尺寸复制、PNG/JPEG 预览导出使用当前层显示画布；透明补空、JPEG 黑／白背景保持原规则，
  异常标记在最终尺寸上绘制。极简窗口显示同一结果。
- 活动图层和整文件原始 EXR 均只保存所选层，采用扫描线，不包含 `tiles` 或完整金字塔。
  保存对话框应显示层号及这一限制。整文件包括该层所有被选中的通道和 parts。
- FLOAT＋ZIP 往返核对原值、通道名称、窗口、part 顺序、`view/multiView` 顺序和基础元数据；
  None 仍可去除可选元数据。裁在预览之外的数据保留在当前层原始输出中。
- 普通源图层 HDR／曝光序列读取当前层显示用线性数据；Anaglyph 仍拒绝活动原始、HDR 和
  曝光序列导出，允许预览及整文件源数据导出。
- 切层准备期间保存应针对已显示的层，不能使用尚未完成的目标层。
