# Unusual Pixel Images 核对清单

本轮修改扫描线预览的数值处理、异常位置标记和统一单通道页面，不扩展 Tiled、Deep 或完整色彩管理。
样例位置为 `OpenEXR Test Images/UnusualPixelImages`，未移动或修改样例文件。

## 已完成的静态审查

- 核对全部 11 张 EXR 的文件头与通道布局；此步骤不解码或渲染像素。
- 源通道读取后、颜色转换前统计有限最小值／最大值及 NaN、正 Inf、负 Inf。
  单位为通道样本，真实 Alpha 计入，补零分量、默认 Alpha 和派生亮度不计入。
  源统计与异常区域共用源通道分类函数。RGB 伪彩色自动范围仍使用有限派生亮度；
  标量自动范围使用有限源样本，没有对应有限样本时禁用 Auto 并显示 `n/a`。
- 缺少或具有标准 `chromaticities` 时跳过色域矩阵。负值与大于 1 的有限值保留在
  浮点数据中，异常判断仅识别非有限值。
- 审查曝光、亮度、色调映射、范围归一化的 double 中间值以及分类、限幅后再转字节
  的顺序。范围输入、滑块、色标和 PreviewState 使用 double；常量范围不依赖加 1 扩展。
- 所有单通道（R/G/B/A/Y/RY/BY/V 等）使用同一 Colormap 页面和单通道数据模型，
  默认灰度色带、范围 0～1、高亮关闭。范围和 Auto 直接使用源样本，不经过曝光、
  sRGB 转换或亮度系数缩放。独立 G 的原始 EXR 导出只有 G 通道，其他单通道同理。
- 合成 RGB/RGBA/YA/YC/YCA 保留颜色预览；颜色模式菜单不改变单通道页面。
  单通道右键重置恢复灰度及 0～1 范围，同时保留高亮开关。
- 异步解码按八邻域合并异常像素，缓存各区域边界、像素数和类别；逐行扫描及区域合并响应取消。
  基础预览不再写入标记色，开关通知视图重绘前景，不发起基础图像重渲染。
  刷新通过图层键恢复 PreviewState；极简窗口使用同一模型；右键重置不修改开关。
- 孤立异常画直径 12 个屏幕逻辑像素的圆圈，连续区域画最小 12 个逻辑像素的外框；
  输出坐标中的重叠标记通过空间网格合并，混合类别优先级为 NaN、正 Inf、负 Inf。
  外框可能包含正常像素；放大进入大区域内部时，外框裁至当前可见图像边缘。
- 两套页面共用 28×28 纯图标按钮与 16×16 矢量定位图标，沿用主题选中、悬停和焦点样式。
- 审查复制和预览导出先缩放基础图像，再绘制标记；原始导出仍读取浮点数据及通道映射。
- 检查 Qt UI XML、自定义控件声明、CMake 源文件登记及补丁空白错误。
- 补充未执行的回归测试：对角连通与桥接、取消、缩小后标记尺寸、开关不重渲染基础图像、
  屏幕重叠标记的类别优先级，以及透明背景上的不透明描边。

以上是源码及文件头审查，不代表编译或画面验收通过。本轮未编译、启动查看器或运行测试。

## 待运行的交互与导出核对

1. 分别在合成 RGB 和单通道预览点击定位图标按钮，悬停显示 `Mark NaN/Inf` 和图例。
   验证 NaN 品红、正 Inf 青色、负 Inf 黄色；混合异常优先级依次为 NaN、正 Inf、负 Inf。
   标记线条不透明、内部不填充，即使源 Alpha 为零也不能隐藏标记。
   检查缩小、100% 和放大状态下的孤立异常，以及密集区域、重叠标记、图像边缘的裁剪。
   检查非方形像素、明暗主题、高 DPI、Tab 聚焦和空格切换；按钮开启状态应清晰可辨。
2. 关闭高亮：普通颜色预览中 NaN／负 Inf 对应分量为黑，正 Inf 为满亮度；
   伪彩色中 NaN 为黑、两种 Inf 分别落在色带两端。合法负值不自动标记。
3. 输入 `-1e38`、`1e38`、`1e-38` 和 FLOAT 次正规数范围，确认输入后、切换模式后及刷新后
   都保留数值。合成 RGB 伪彩色的范围单位是亮度；所有单通道直接使用各自源值，
   独立 G 不乘 0.7152。比较 R/G/B/A/Y/V 的控件，确认页面一致，颜色模式菜单不改变它们。
4. 令范围上下限相同，确认有限值落在色带下端；数据边界也相同的滑块应禁用。
   补充全非有限样本的人工核对，确认统计为 `n/a` 且 Auto 不可用。
5. 打开多个图层，分别设置开关；切换模式、刷新、进出极简窗口以及右键重置后，
   确认各图层开关不串联。单通道右键重置应恢复灰度和 0～1 范围，并保留高亮开关。
   快速连续切换开关，确认最终预览对应最后一次选择。
6. 复制全分辨率与缩小预览，导出原尺寸与缩小 PNG，确认缩放后的图像上仍有 12 像素圆圈。
   导出原始 EXR 再核对通道名和数值，
   确认没有写入标记色。为保留 WideFloatRange 的数值范围，应选 FLOAT 与无损压缩；
   HALF 输出无法容纳该样例的极大数值。JPEG 有损压缩可能改变标记颜色，
   精确颜色核对使用 PNG，并避开抗锯齿边缘。
