## 样例范围

位于 `OpenEXR Test Images/MultiResolution`。每组四个 Deep 文件，RGBA 为 HALF、Z 为 FLOAT，
采样率均为 1；没有 ZBack。各 part 使用自己的 Data Window。

|---|---|---|---|
| LeftView | Balls.exr | 1920×1080，左眼 | 缩窄 Z 区间，球体逐个出现／消失；前后遮挡及边缘 |
| LeftView | Ground.exr | 同上 | 地面随深度区间被截取，空位置显示棋盘格 |
| LeftView | Leaves.exr | 同上 | 树冠细节、密集样本及快速拖动响应 |
| LeftView | Trunks.exr | 同上 | 树干的前后关系、细边缘及空区间 |
| LowResLeftView | Balls.exr | 1024×576，左眼 | 较低分辨率下的球体与定位 |
| LowResLeftView | Ground.exr | 同上 | 地面和补空，不以放大图要求逐像素一致 |
| LowResLeftView | Leaves.exr | 同上 | 树冠边缘与窄区间 |
| LowResLeftView | Trunks.exr | 同上 | 树干边缘与窄区间 |

参考 JPG 只用于理解场景及构图，不作为逐像素色彩基准。

## 操作与画面

1. 默认 Depth Range 覆盖全部有限 Z。左手柄控制 Z_min，右手柄控制 Z_max；端点包含在区间内。
   双击恢复全部深度。把区间收窄到没有样本的深度缝隙，应只剩棋盘格。
2. 分别缩窄近端和远端，确认球、树冠、树干按深度出现／消失；边缘可能随入选样本改变。
   合成按 Z 从近到远进行，同深度保持源文件顺序。无需点击像素打开样本表。
3. 悬停显示文件坐标及 `Composite` 合成线性值，位于曝光／色调映射／色带映射之前。
   独立 R/G/B/A 与相同区间的颜色页面分量一致；独立 Z 显示最近入选样本。
   没有入选样本显示 `No samples`，不伪装成数值 0。
4. 已入选像素采用不透明黑底语义；零 Alpha 发光不能消失，部分 Alpha 不能被重复相乘。
   未入选像素透明。Display Window 裁剪、补空、像素比例、裁剪图标及取值坐标保持原有规则。
5. Auto 只计算当前合成画面中有样本且有限的值，不把透明空位置作为零参与范围。
   手动色带范围保持不变；源统计包含整个源 part 的所有真实通道样本，不随深度滑条变化。
6. 异常标记随入选样本变化；非有限 Z 不参与合成或深度范围，但仍保留在源统计及独立 Z 标记中。
   滤掉全部有限样本时，Z 页面仍可能显示用于定位非法 Z 的标记。
7. 快速连续拖动后，画面、悬停读数、Auto 和标记必须对应最后一次选择。
   原始样本只读取一次并由同 part 页面共享；拖动不重新解码文件。
8. 刷新及进出极简窗口保留区间。极简底栏的同款滑条直接操作原页面。
   右键重置颜色参数不改变深度范围。刷新后手动区间裁到新范围，完整范围随新文件重新计算。
9. Stereo 的新 Anaglyph 继承当前区间，两眼共用同一 Z 区间。
   鼠标分别显示两眼当前合成结果，缺失眼标为无样本／无数据。双眼都没有样本处透明。
   左右眼源页面各自保存范围，之后修改 Anaglyph 不反向改动源页面参数。

## 输出与异常路径

- 复制、PNG、JPEG 反映当前区间。PNG／剪贴板保留空区间透明度，JPEG 黑／白背景选项正常；
  缩小后再画异常标记。普通 Deep 源的 HDR／曝光序列使用当前线性合成结果。
- 活动原始及整文件原始 EXR **不受区间影响**，保留全部样本数量、顺序、值和原通道类型，
  输出为 `deepscanline`、无损 ZIPS。活动通道输出补齐 A/Z；仅颜色筛选的独立 Z 明确失败。
- 保存对话框说明固定压缩及类型、完整样本导出；Basic 保留色域／视图及像素比例，
  None 可去除可选元数据，Deep 必需结构始终存在。含 Deep 的多 part 只能 Preserve multipart。
- Anaglyph 仍禁止活动原始、HDR 和曝光序列导出；可复制、保存 PNG/JPEG 或导出整文件原始 EXR。
- 常量深度禁用拖动；全无有限 Z 时显示 n/a，画面无入选样本。普通图像没有 Depth Range 控件。
- Deep 只允许层级 `(0,0)`；Deep Tiled、ZBack 体积输入明确报错。
  每 part 原始缓存上限 1 GiB；样本数量／偏移／字节数超限、分配或读取失败均不能发布部分结果。
  刷新失败保留旧画面。
