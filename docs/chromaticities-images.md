# Chromaticities 核对清单

范围为 `OpenEXR Test Images/Chromaticities` 的全部 4 张 EXR；样例未修改。
本轮仅做静态源码审查，未编译、启动查看器或运行测试，以下画面均待人工验收。

## 数据与显示约定

- 四张图均为 610×406、PIZ 压缩的 HALF 扫描线图像。Rec709 文件没有 chromaticities，
  按默认 Rec.709 处理；XYZ 文件具有 XYZ 基底及等能白点描述，原色坐标含合法的 y=0。
- RGB 源通道仍名为 R/G/B，XYZ 编码不擅自改名。原始数据与显示缓冲分开，源统计和
  异常分类先于颜色转换。标准／缺少色域时跳过矩阵，非标准矩阵组合和像素乘法使用 double。
- 两张 YC 图的 Y 为 1×1、RY/BY 为 2×2。先按源色域权重重建 RGB，再做源色域到线性
  Rec.709 的转换。不增加白点适配、完整 ACES 显示变换或 OCIO。
- YC 原始取值与导出保留源 Y/RY/BY；基础元数据模式保留源色域，None 可去除。
  活动图层不再输出还原后的 RGB。HDR 和曝光序列始终使用显示用线性颜色。
