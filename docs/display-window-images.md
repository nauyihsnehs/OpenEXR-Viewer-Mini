# Display Window 人工核对清单

本组 16 张 EXR 的头信息已静态核对，均含 400×300 个源像素。以下画面与操作仍需运行查看器人工验收；没有编译、启动查看器或运行回归测试。

## 显示规则

- 所有合成颜色和独立通道预览均以 Display Window 为画布；窗口外源数据不显示。
- 缺失数据在界面显示棋盘格，悬停不显示源读数。实际数据继续使用原有颜色或 Colormap 映射，不用源 Alpha 挖空预览。
- 复制与 PNG 预览导出对缺失区域保留透明；JPEG 可通过 `Transparency background` 选择 `Black (0)` 或 `White (1)`，默认黑色。选择随其他保存参数在本次程序会话中记住；部分透明像素在该背景上进行 Alpha 合成。棋盘格不是导出像素内容。
- RGB、单通道与极简窗口信息栏共用 16×16 裁剪图标。只有源数据在显示窗口外才显示；悬停说明方向，以及完全无交集的情况。图标不属于复制或导出的图像。
- Data Window 尺寸是源像素数组尺寸；Display Window 尺寸是文件定义的画布尺寸；方形像素预览输出尺寸还包含像素宽高比修正。
- 100% 时源像素高度为一个逻辑像素，宽度乘像素宽高比。全尺寸导出高为显示窗口高度，宽为显示窗口宽度乘比例后四舍五入，最小为 1；限宽之后再画异常标记。
- 原始 EXR 导出保留完整源数据及两个窗口，Basic 元数据保留像素宽高比；None 沿用现有去除可选元数据规则。HDR 与曝光序列本轮未改变。

## 交互、状态与输出

- RGB 和独立通道具有相同边界。缩放、平移均不能显露被裁掉的数据；适应窗口以显示画布为准。
- 核对裁剪图标：t02/t03 提示左、上；t04 提示右、下；t05 提示四边；t09～t12 分别提示左、右、上、下，并注明全部数据在窗口外；t13 提示左、上，t14 提示右、下。t01、t06～t08、t15、t16 隐藏图标。方向依据窗口范围，而不是扫描像素颜色。
- 切换图层、刷新、进出极简窗口后图标与提示同步，不残留上一张图的状态；明暗主题、高 DPI 下均清晰可见且不能点击。
- 源像素取值使用文件坐标，负坐标和非零起点没有重复偏移；补空区及窗口外清空读数。
- 棋盘格区域也可双击切换极简窗口、右键重置，包括 t09～t12；极简窗口按显示画布及像素比例定尺寸。
- 刷新、进出极简窗口保留当前预览参数、异常开关和普通视图位置；右键重置不改变异常开关。
- 使用额外异常夹具核对裁剪边缘：窗口外区域不参与标记，标记只画在可见数据内；原始统计仍包含窗口外异常。放大、缩小、非方形像素、明暗主题和高 DPI 均待人工核对。
- 全尺寸及限宽复制、PNG/JPEG 预览导出具有相同裁剪和位置；标记在最终尺寸绘制，透明补空不会被标记污染。
- 仅在 `Preview Image + JPEG` 显示背景选项；切换 PNG、原始导出或曝光序列时隐藏。检查黑／白背景、再次打开保存对话框的选择恢复，及 PNG/复制透明度保持。源 Alpha=0 的发光颜色仍按现有不透明预览保留，不被背景选项覆盖。
- 活动图层和整文件 FLOAT＋ZIP 原始导出重新打开后，核对源像素、两个窗口及 Basic 模式像素比例；确认裁剪没有丢弃文件数据。
