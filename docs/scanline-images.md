# ScanLines 核对清单

范围为 `OpenEXR Test Images/ScanLines` 中全部 9 张 EXR。本轮沿用扫描线解码，
不扩展 Tiled、Deep、白点适配或完整 ACES/OCIO 色彩管理，不移动或修改样例文件。

## 显示与数据约定

- 合成 RGB/RGBA/YA/YC/YCA 固定黑底、输出不透明预览。OpenEXR 预乘颜色在黑底上的
  结果就是 RGB，不再乘或除以 Alpha；A=0 的发光颜色保留。
  依据：[OpenEXR 预乘颜色说明](https://openexr.com/en/latest/TechnicalIntroduction.html#premultiplied-vs-un-premultiplied-color-channels)。
- 曝光、色调映射、伪彩色亮度、HDR 及曝光序列输出使用显示用线性颜色。
  源 Alpha 保留在原始数据、统计、异常分类和独立 A 页面中。
- 仅在非标准 RGB 色域需要矩阵转换时额外保存源缓冲。矩阵组合及像素乘法使用 double
  中间值；矩阵系数沿用 OpenEXR 的 RGB→XYZ→Rec.709 接口。缺少或具有标准色域时跳过转换。
- 原始取值和原始 EXR 导出读取源缓冲。基础元数据模式保留对应 `chromaticities`，
  显式 None 可去除；活动图层和整文件导出均适用。后续 YC 修正已将 YC/YCA 活动图层
  原始导出统一为源 Y/RY/BY/A、源采样率及源色域；显示和 HDR／曝光序列仍使用还原后的 RGB。
- 多 part 合并若色域不一致，基础元数据模式拒绝合并并提示保留 parts，避免错误标注。
- 悬停文本显示局部位置加 `dataWindow.min` 后的文件坐标；数组、视图及标记继续用局部坐标。
  图像外画布、统一单通道 Colormap 页面、刷新和极简窗口流程保持现状。

## 静态审查范围

- 源统计和异常区域仍在色域转换前生成，真实 Alpha 参与分类；原始数据不含标记。
- 解码完成后统一发布不可变数据，异步渲染按值捕获其共享所有权与模式参数，
  源缓冲随同一数据对象存活；矩阵转换逐行检查取消，未增加 UI 状态捕获。
- `getRawPixels()`、通道分量取值、原始 EXR 输出使用源值；基础渲染、派生亮度、
  HDR 和曝光序列使用显示缓冲。单通道不做色域转换。
- 复制和 PNG/JPEG 预览输出复用不透明基础图，先缩放再绘制异常标记。
  模型与 PreviewState 的刷新、极简窗口及开关恢复路径无需变更。
- 更新 YA 预览 Alpha 的旧预期；补充未执行的回归测试：零 Alpha 发光、部分 Alpha
  不重复衰减、三种颜色模式不透明、PNG 预览一致、AP0 源值隔离、活动／整文件原始 EXR
  保留源值与可选色域、曝光序列使用显示值，以及负起点、扩大数据窗口和倒序扫描线。
- 执行补丁空白检查与调用路径审查。

以上仅为静态源码审查。本轮未编译、启动查看器或运行测试，不代表 9 张图已通过运行验收。

## 待人工核对

参考 JPG 仅比较构图和可见内容，不作为逐像素色彩基准。下表所有画面项目均未执行。

| 样例 | 核对重点 |
| --- | --- |
| CandleGlass | A=0 且 RGB 非零的火焰保留；半透明边缘不重复变暗；调整曝光并对比复制、PNG/JPEG 预览。 |
| PrismsLenses | 黑底上的光束及零 Alpha 发光区域可见；曝光、色调映射和伪彩色均不受 Alpha 隐藏。 |
| Carrots | AP0 只转换显示颜色；合成图层 R/G/B/A 取值与独立通道一致。FLOAT、无损原始导出的值与色域均保留；None 去除色域说明。 |
| Blobbies | 负起点 (-20,-20)、大于显示窗口的数据窗口、倒序扫描线定位正确。四角取值无翻转，悬停包含负坐标，Z 使用现有标量页面。 |
| Tree | 非标准色域仅影响显示，源值、Alpha 与独立通道一致；原始 EXR 再打开仍具有对应色域。 |
| Cannon | 无 Alpha RGB、B44 压缩读取、曝光和颜色模式回归；默认合成 Alpha 不纳入源统计。 |
| Desk | 普通 RGBA 的曝光、色调映射、黑底复制及预览导出一致。 |
| MtTamWest | RGBA 风景的曝光及高亮细节，黑底复制／导出，无额外 Alpha 衰减。 |
| StillLife | 普通 RGBA 的颜色与边缘、曝光、色调映射，以及全分辨率和缩小预览导出。 |

跨样例检查：切换图层、刷新和进出极简窗口后预览状态保留；NaN/Inf 标记最后绘制，
不受 Alpha 影响；独立 A 仍为源值灰度／Colormap。原始 EXR 选择 FLOAT 与无损压缩来核对
源值，HALF 转换或有损压缩不可作为精确值回归基准。
